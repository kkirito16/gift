# UniqueBirthdayGift · 致最爱的妈妈

一份给妈妈的生日礼物：一张可以「吹蜡烛、放天灯、拆信」的互动网页贺卡。

打开 `index.html` 即可，无需构建、无需依赖。

## 四幕

| 幕 | 内容 | 交互 |
|---|---|---|
| 一 | 封面 | 点「拆开礼物」进入 |
| 二 | 生日蛋糕 | 吹灭三支蜡烛（点击 / 麦克风 / 一键吹灭） |
| 三 | 放飞心愿 | 写下想说的话，随天灯升上夜空 |
| 四 | 一封家书 | 拆开火漆信封，信纸逐句浮现，盖下印章 |

## 玩法

- **吹蜡烛**：点击烛火逐支吹灭；或授权麦克风后对着屏幕吹气（有音量条反馈）；也可以一键全吹灭。全部熄灭后会撒下纸屑。
- **放天灯**：在输入框写下想对妈妈说的话，点「放飞天灯」，可以连放多盏，灯笼会带上你写的字慢慢飘远。
- **拆信**：点击信封，蜡封打开、信封翻盖、信纸滑出，祝福逐句浮现，最后盖上一枚朱红印章。
- **抽祝福签**：信下方的祝福签可以反复翻牌，共六条祝福语。
- **导航**：左右方向键、底部圆点、前进后退箭头都能切换；也可以用 `#0`~`#3` 直接跳到某一幕。

配乐与音效由 Web Audio 实时合成（无外部音频文件），右上角可随时静音。

## 本地预览

吹蜡烛需要麦克风，浏览器只在 `localhost` 或 https 下开放麦克风权限。直接双击打开也能看，只是用不了「吹气灭烛」。

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
