# UniqueBirthdayGift

一份给妈妈的生日礼物：一张可以「吹蜡烛、放天灯、拆信」的互动网页贺卡。

打开 `index.html` 即可，无需构建、无需依赖。

> 项目里不含任何个人信息。祝福语、署名、日期都放在一处配置里，改成自己想送的人就行 —— 见「自定义贺卡内容」。

## 四幕

| 幕 | 内容 | 交互 |
|---|---|---|
| 一 | 封面 | 点「拆开礼物」进入 |
| 二 | 生日蛋糕 | 吹灭蜡烛（点击 / 麦克风 / 一键吹灭） |
| 三 | 放飞心愿 | 写下想说的话，随天灯升上夜空 |
| 四 | 一封家书 | 拆开火漆信封，信纸逐句浮现，盖下印章 |

## 玩法

- **吹蜡烛**：点击烛火逐支吹灭；或授权麦克风后对着屏幕吹气（有音量条反馈）；也可以一键全吹灭。全部熄灭后会撒下纸屑。
- **放天灯**：在输入框写下想说的话，点「放飞天灯」，可以连放多盏，灯笼会带上你写的字慢慢飘远。
- **拆信**：点击信封，蜡封打开、信封翻盖、信纸滑出，祝福逐句浮现，最后盖上一枚朱红印章。
- **抽祝福签**：信下方的祝福签可以反复翻牌。
- **导航**：左右方向键、底部圆点、前进后退箭头都能切换；也可以用 `#0`~`#3` 直接跳到某一幕。

配乐与音效由 Web Audio 实时合成（无外部音频文件），右上角可随时静音。

## 自定义贺卡内容

**所有文案都集中在 `index.html` 顶部的 `CARD` 配置里**，改完保存、刷新页面即可生效，其它代码都不用动。

打开 `index.html`，往下翻一点点就能看到：

```js
const CARD = {
  // 封面
  cover: {
    to: 'To 最爱的妈妈',       // 封面主标题
    sub: '生日快乐',            // 封面副标题（同时是浏览器标签标题）
    peek: 'To 最爱的妈妈 ……'    // 信封口露出的一行小字
  },

  // 信纸（第 4 幕）
  letter: {
    greeting: 'To 最爱的妈妈：', // 信开头的称呼
    lines: [                     // 正文，一行一个字符串，随便增删
      '祝您生日快乐！',
      '健康、幸福、好运、开心',
      '愿新的一岁',
      '无事绊心弦，所念皆如意。'
    ],
    sign: ['你的儿子', '你的名字', '2022.11.2'] // 署名，一行一个
  },

  // 祝福签（第 4 幕下方，随便增删）
  fortunes: [ ... ],

  // 放天灯时输入框为空的默认心愿
  defaultWish: '愿妈妈健康、幸福、好运、开心',

  // 蛋糕上的蜡烛数量
  candleCount: 3
};
```

常见改法：

| 想改什么 | 改哪里 |
|---|---|
| 送给别人（比如爸爸、朋友） | `cover.to`、`cover.peek`、`letter.greeting` |
| 祝福正文、加几句或减几句 | `letter.lines`，数组里一行一个字符串 |
| 署名和日期 | `letter.sign`，一行一个字符串 |
| 祝福签内容 / 条数 | `fortunes`，数组里随便增删 |
| 蜡烛数量 | `candleCount`（蛋糕大小和蜡烛数会自动排布） |
| 封面图 | 替换根目录的 `background.png` |
| 配色 | `index.html` 里 `:root` 的 CSS 变量（墨绿 / 奶油 / 烫金 / 印泥红） |

## 本地预览

吹蜡烛需要麦克风，浏览器只在 `localhost` 或 https 下开放麦克风权限。直接双击打开也能看，只是用不了「吹气灭烛」。

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 文件

```
index.html          贺卡本体（CARD 配置 + 结构 + 样式 + 交互，单文件）
background.png      封面贺卡图
assets/
  seal.png          朱红「生日快乐」印章
  envelope.png      开口信封
  wax.png           「福」字火漆蜡封
  lantern.png       孔明灯
  paper.png         信纸纹理
  favicon.png       标签页图标
```

蜡烛、信封、天灯均为 CSS / 程序绘制，配色取自 `background.png`：墨绿 `#2f6b47`、奶油 `#fdf6e3`、烫金 `#c9a24a`、印泥红 `#be362c`。

## 其它

- 响应式适配手机，支持 `prefers-reduced-motion`（系统开启「减弱动态效果」时自动关闭动画）。
- 仓库里没有个人信息，`git` 历史里若仍有旧内容请自行 `git log -p` 确认。
